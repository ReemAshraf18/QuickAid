# QuickAid 🩺

QuickAid is a responsive healthcare and emergency assistance web application designed to provide quick access to first-aid information and healthcare services in Aswan, Egypt.

The platform allows users to search for hospitals, pharmacies, and private clinics, view detailed healthcare profiles, follow providers, exchange messages, and access common first-aid guidance through an interactive FAQ chatbot.

## ✨ Features

* 🏥 Search and browse hospitals in Aswan
* 💊 Search pharmacies and view available medicines and offers
* 👨‍⚕️ Browse private clinics and doctor information
* 🔎 Smart search with category filtering
* 🩹 Interactive First Aid guide
* 👤 Customer registration, login, and profile management
* 🏢 Dedicated dashboards for pharmacies, hospitals, and clinics
* ❤️ Follow and unfollow healthcare providers
* 💬 Customer-to-provider messaging
* 🤖 Interactive FAQ chatbot
* ⭐ Ratings and reviews
* 📍 Google Maps search integration
* 📋 Customer search history
* 📊 Healthcare dashboard and demo statistics
* 📱 Fully responsive Bootstrap design

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Bootstrap 5
* Bootstrap Icons

## 📍 Data

QuickAid currently focuses on healthcare providers in **Aswan, Egypt**.

The project uses publicly available healthcare directory information as demo/project data. Missing or unverified information is clearly marked rather than being fabricated.

## ⚠️ Project Status

QuickAid is currently a **frontend prototype** created for educational/project purposes.

Authentication, messaging, dashboards, and data management are simulated on the frontend. A production version would require a secure backend, database, authentication system, and real-time communication infrastructure.

## 🎯 Project Goal

The goal of QuickAid is to provide a simple and accessible platform that connects users with healthcare services while making essential first-aid information easier to access.
